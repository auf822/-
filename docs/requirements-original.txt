研究生导师双向选择系统需求设计文档
1 系统概述
1.1 开发背景
随着研究生招生规模逐年扩大，传统线下人工选导方式存在流程繁琐、统计困难、信息不透明、工作量大、易出错等诸多问题。为规范学院研究生导师遴选与师生配对流程，保障本院研究生与导师双向选择的公平、公正，提升学院教务管理效率，简化院内师生双选操作流程，特开发本学院级研究生导师双选系统。
本系统立足二级学院实际教务场景，摒弃通用型系统冗余功能，聚焦学院专属双选业务，实现导师信息管理、学生志愿填报、导师意向审核、名额动态管控、二轮补选调剂、数据统计归档全流程线上化，解决传统人工管理的各类痛点。
1.2 系统定位
学院级研究生导师双选系统是一款面向高校二级学院专属教务场景的轻量化、高安全、高适配的线上双选管理平台。系统基于B/S架构开发，无需用户安装客户端，通过浏览器即可登录操作，仅服务于单学院内部师生双选工作。
系统核心实现本院学生志愿填报、本院导师择优录取、院内名额实时管控、院内智能匹配、学院数据可视化统计、结果导出归档一体化功能，打通学院教务、本院导师、本院学生三方数据壁垒，实现学院层级双选流程标准化、透明化、精细化管控。

2 系统角色与权限体系
系统采用四级精细化权限分级管理模式，贴合学院信息化管理架构，设置超级管理员顶层权限，可自主指定、分配学院专项管理账号，将学院管理岗细分为研究生辅导员、科研秘书两个专属岗位，各角色权限独立隔离、分工明确、互不越界，精准适配学院规范化双选管控工作。具体角色及权限定位如下：
2.1 超级管理员（顶层管理角色）
系统最高权限负责人，拥有全局管理权限。核心专属权限为指定、配置、新增、解绑学院研究生辅导员与科研秘书账号，可自定义两类管理岗的操作权限范围；同时支持系统基础参数初始化、全员账号管控、权限重置、操作日志总览、数据最高权限审核，统筹全院双选系统正常运行。
2.2 学院科研秘书（专项管理角色）
由超级管理员指定授权，独立负责全院导师招生名额管控。支持批量录入/修改全院导师年度招收学生上限名额，也可针对单个导师手动调整招生名额；支持一键导出全院导师名单表格，线下填写各导师招收学生数量后批量导入系统，实现导师招生名额的批量设置与更新；系统搭载剩余名额全自动更新机制，可根据导师预录取、正式匹配、取消录取、名额调整等操作，实时动态刷新导师剩余招生名额，名额用尽自动锁止报名通道，全程无需人工统计更改，精准管控全院各专业招生总额度。科研秘书无任何双选结果解除、改选、调剂权限，无法更改已生效的师生配对结果，权责专一。
2.3 学院研究生辅导员（核心管理角色）
由超级管理员指定授权，负责本院师生基础信息管理、双选规则配置、全流程管控，可自主设置学生意向导师填报数量，拥有导师信息、学生信息手动新增、批量导入、编辑纠错，双选时间配置、进度监督、人工调剂、二轮补选手动开启、数据统计、结果审核与导出归档等全流程权限。同时拥有全院唯一的已配对结果解锁、解除、调整权限，可处理师生选定后的特殊改选、退选需求。
2.4 本院导师用户
仅可查看意向填报自己的本院学生信息，无法查看全院其他学生、其他导师的双选数据，实现数据完全隔离。可结合个人招生名额择优筛选、审核学生意向（确认/拒绝）、确认最终配对结果；可自主编辑修改个人简介、研究方向、科研成果等公示信息，提交后经辅导员审核生效；可查看自身双选配对结果与招生数据。师生双向选定配对生效后，导师无权解除、撤销已选定结果，无法自主退选学生。
2.5 本院研究生学生用户
仅浏览本院可选导师基础公示信息、填报双选志愿、查询个人双选进度及最终配对结果，完成院内双选操作。学生端不展示导师招生总名额、剩余可招人数，仅在提交志愿时校验名额状态。师生双向选定配对生效后，学生无权自主解除、撤销、更改导师选择结果，无法私自改选其他导师。系统自动过滤年度招生名额为0的导师，该类导师不在学生端列表展示。
3 系统核心业务流程
本系统双选流程遵循信息初始化→首轮志愿填报→导师审核配对→首轮结果锁定→辅导员名额微调→辅导员手动开启二轮补选→最终结果审核归档的标准化闭环流程，全程配套导师剩余名额自动更新、配对结果权限锁定、二轮专项补选、学生端名额隐藏、零名额导师过滤等专属机制。
3.1 完整业务流程步骤
3.1.1 系统初始化与信息准备阶段
超级管理员完成系统顶层初始化，授权指定本届研究生辅导员、科研秘书管理账号，完成权限分配。研究生辅导员批量/手动导入本届新生学生信息；本院导师基础信息一次性入库保存，无需每一年进行全量重新导入，辅导员可在系统内对导师信息执行新增、删除、修改、查询操作，按需维护导师名录。科研秘书录入各导师年度最大招生名额，系统自动初始化导师剩余可招名额。其中，年度招生名额配置为0的导师，系统自动隐藏，不展示在学生端导师列表。导师可登录系统自主修改、完善个人简介与研究方向信息，提交后由辅导员审核生效。研究生辅导员设置本届双选规则（学生可填报意向导师数量、首轮双选时间周期）。
3.1.2 首轮学生志愿填报与导师审核阶段
双选首轮通道开启后，学生根据学院设定的志愿数量，自主选择意向导师并提交申请。学生端页面仅展示导师个人简介、研究方向等基础信息，不展示导师招生总名额、剩余可招人数。系统严格数据隔离，导师仅可查看填报自己意向的学生，无法查看全院其他学生数据。导师针对学生意向执行两种操作：确认接收或拒绝意向。导师确认接收后，师生配对锁定，系统自动扣减导师剩余名额，学生无法继续填报或更换导师；导师若拒绝学生意向，该条志愿自动失效，学生将重新获得意向填报权限，可继续选择其他导师。
3.1.3 首轮结果锁定与权限管控阶段
首轮双选时间截止后，系统自动关闭首轮填报入口，锁定所有已配对师生结果。所有已选定配对结果默认锁定，学生、导师、科研秘书均无权限解除或修改，仅研究生辅导员拥有唯一解锁、调整、解除配对的权限。系统自动区分两类学生群体：首轮已成功匹配导师的学生、首轮未匹配任何导师的学生，为二轮补选提供数据支撑。
3.1.4 辅导员名额微调与第二轮补选开启阶段
首轮双选结束后，第二轮补选通道默认关闭、不会自动开启。研究生辅导员可根据全院首轮招生结余情况、导师空余名额，对各导师招生名额进行二次微调与优化配置。名额调整完成确认生效后，由辅导员手动开启第二轮专项补选通道并配置二轮时间窗口。系统做严格权限区分：仅首轮未匹配导师的学生可参与第二轮志愿选择，已匹配学生无法进入本轮填报，杜绝重复选导、抢占名额等情况。未匹配学生可在二轮周期内重新填报意向导师，学生端同样不展示导师招生总名额与剩余名额；导师继续执行意向审核（确认/拒绝），系统后台实时更新剩余名额，到达截止时间后系统自动关闭二轮填报入口。
3.1.5 最终结果审核与归档导出阶段
第二轮补选周期结束后，系统彻底关闭所有填报通道，锁定全院最终师生配对结果。研究生辅导员统一审核全部配对数据，处理特殊调剂与异常数据，审核无误后批量导出全套双选结果报表、导师招生汇总表、学生配对明细表，用于学院教务归档、院内留存及上报研究生院。系统全程留存所有填报、审核、调剂、名额调整操作日志，数据永久可追溯。
3.2 特殊场景与机制说明
•	导师名额后台自动更新与锁止机制：系统后台根据学生填报、导师确认录取、二轮名额调整、取消配对等所有操作，实时动态刷新导师剩余招生名额；名额耗尽后后台自动拦截新的志愿提交请求，学生端不会展示名额相关数字，仅在提交志愿时若导师名额已满，提示无法提交该志愿。当年招生名额设置为0的导师，不在学生端导师列表中展示。
•	拒绝意向自动重置机制：学生提交意向后，若导师审核拒绝，本条志愿自动失效，学生自动恢复填报名额，可继续选择其他导师，不占用志愿次数。
•	配对结果权限锁定机制：师生双向确认配对后结果自动锁定，仅研究生辅导员拥有唯一解除、调整权限，其余角色无权改动，保障双选结果严肃性。
•	二轮补选人工手动开启机制：首轮双选结束后，第二轮补选通道默认关闭、不会自动开启。必须由研究生辅导员完成名额微调后，手动主动开启第二轮选择通道并配置时间窗口，系统才对未匹配学生开放二轮填报权限，严格管控双选各阶段进度。
•	二轮补选人员隔离机制：第二轮选择通道严格隔离人群，仅首轮未匹配学生拥有填报权限，已匹配学生无任何操作入口，保证补选公平性。
•	志愿修改超时机制：各轮次填报截止后，自动锁定对应轮次志愿数据，学生无法新增、修改、撤销志愿。
•	导师基础信息长效维护机制：本院导师基础信息一次性入库持久存储，无需每一年进行全量重新导入。辅导员可在系统中对导师基础信息执行新增、删除、修改、查询操作，实现导师名录常态化维护；导师个人简介、研究方向等内容可由导师本人提交编辑，经辅导员审核后生效。
4 系统详细功能模块
4.1 超级管理员顶层功能模块
4.1.1 系统全局参数配置
负责系统初始化基础配置，统一设置每年度双选起止时间、各专业招生总名额、师生匹配优先级规则等核心参数；支持学年信息新建、切换、归档，实现学院每学年双选数据独立管理、互不干扰，适配学院每年个性化双选规则调整。
4.1.2 学院管理岗账号授权管理
为本角色核心专属功能，支持超级管理员自主指定、新增、解绑、重置研究生辅导员账号和科研秘书账号，可单独分配、收回两类岗位的专属操作权限，支持权限精细化微调。同时统一管理全院导师、学生账号，可批量新增、导入、删除、禁用账号，支持账号密码批量重置。全程记录所有管理岗操作日志，可追溯岗位操作记录，保障院内权限管控规范有序。
4.1.3 全流程数据总览与权限管控
超级管理员拥有系统最高数据查看权限，可全局监控本院双选整体进度、各岗位操作情况、师生双选数据、名额使用情况；支持全院所有数据报表、双选结果汇总导出，可审核辅导员、科研秘书的所有操作记录，拥有最高数据复核与权限管控能力。
4.2 学院双岗管理员功能模块
4.2.1 研究生辅导员专属：双选规则自主配置
为研究生辅导员专属配置权限，可根据学院当年研究生招生工作要求，统一设置全院学生意向导师填报数量，自定义学生可填报的志愿导师个数，支持按学年灵活调整，系统根据配置参数自动限制学生志愿填报上限，规范全院双选填报规则。同时可管控全院双选起止时间、各专业匹配优先级等基础双选参数，自主把控院内双选整体规则。
4.2.2 研究生辅导员专属：师生信息管理
支持两种信息录入模式，适配学院信息录入场景：一是批量自动导入，支持Excel模板批量上传本院导师基础信息、新生学生信息，系统自动校验数据、批量入库；二是手动单独新增，针对个别遗漏、新增的师生信息，支持单人手动录入、编辑、提交。同时支持信息修改、审核、纠错，确保全院师生数据准确无误。导师基础信息长效保存，无需年度全量导入，仅需常态化增删改查维护。
4.2.3 研究生辅导员专属：双选进度提醒管控
实时查看本学院学生志愿填报进度、导师筛选进度、各导师名额剩余情况；针对超时未操作的师生，可手动发起提醒、统一督促，把控全院双选整体节奏。
4.2.4 研究生辅导员专属：人工调剂与二轮补选管控
首轮双选结束后，可根据院内招生实际情况微调各导师招生名额，手动开启或关闭第二轮补选通道，配置二轮填报时间窗口，精准管控未匹配学生的补选工作。同时针对特殊情况可人工调剂师生配对关系，优先匹配相同专业、研究方向相近的师生，所有调剂操作全程留痕，支持备注说明调剂原因。拥有全院唯一的已配对结果解锁、解除、调整权限，可处理师生选定后的特殊改选、退选需求，其他角色无任何结果解除权限。
4.2.5 研究生辅导员专属：本院数据统计导出
自动统计本学院师生配对率、各导师招生完成情况、未匹配学生明细、各专业双选完成数据，支持明细数据、汇总报表一键导出存档。同时新增双选结果专项导出功能，辅导员可一键导出本院最终师生配对总表、分专业配对明细表、导师招生录取汇总表，导出文件为标准Excel格式，支持直接用于学院教务归档、年度数据上报及研究生院备案。
4.2.6 科研秘书专属：导师招生名额管理
科研秘书由超级管理员授权开通专属权限，独立负责全院导师招生名额管控。支持批量录入/修改全院导师年度招收学生上限名额，也可针对单个导师手动调整招生名额；支持一键导出全院导师名单表格（含导师基础信息及招生名额填报栏），线下填写各导师招收学生数量后批量导入系统，系统自动校验并更新导师招生名额，简化批量名额设置流程；系统搭载剩余名额全自动更新机制，可根据导师预录取、正式匹配、取消录取、二轮名额调整等操作，实时动态计算、刷新导师剩余招生名额，名额用尽自动锁止报名通道，全程无需人工统计更改，精准管控全院各专业招生总额度，该权限与辅导员权限相互独立、各司其职。科研秘书无任何双选结果解除、改选、调剂权限，无法更改已生效的师生配对结果。
名额自动更新触发规则：学生成功填报志愿、导师确认预录取学生、系统智能匹配成功、人工调剂增减学生、取消录取、二轮名额调整等所有改变导师招生人数的操作，系统均会即时刷新剩余名额数据，后台实时同步更新，保证全院名额数据零延迟、零误差。
导师名单批量导出导入规则：科研秘书可一键导出全院导师名单标准Excel表格，表格包含导师工号、姓名、专业、职称等基础信息及招收学生数量填报列；科研秘书在线下填写各导师招收学生数量后，重新导入系统，系统校验导师信息一致性、名额数值合法性，校验通过后自动更新导师招生名额；导入失败时返回错误明细行，便于修正后重新导入。
4.3 院内导师功能模块
4.3.1 个人资料自主管理
导师可自主编辑、修改个人公示资料，包含个人简介、研究方向、科研项目、招生说明、个人成果等对外展示信息。编辑提交后内容进入待审核状态，经学院研究生辅导员审核通过后，方可在系统前台公示展示，确保导师招生信息规范、准确、有效。
4.3.2 学生意向审核（确认/拒绝）
导师系统权限严格隔离，仅能够查看主动意向填报自己的学生信息，无法浏览、查询本院其他学生、其他导师双选数据，实现各导师数据独立隔离、互不互通。可查看意向学生的学号、成绩、报考专业、志愿填报时间等详细信息，支持按成绩、填报时间筛选排序，便于择优筛选学生。可结合自身招生名额自主选择预录取学生、拒绝学生，随时处理意向申请；每一次录取、取消录取操作后，系统自动更新剩余招生名额，实时展示已录取人数、剩余可招人数，名额达到上限后自动禁止新增录取操作，避免超名额招生。师生双向选定配对生效后，导师无权解除、撤销已选定结果，无法自主退选学生。导师拒绝学生意向后，该学生意向自动失效，系统自动释放学生填报权限。
4.3.3 个人双选数据查看
双选结束后，可随时查看个人全部双选信息、历年招生记录，清晰查看本届所有主动填报自己意向的学生、已确认配对学生明细，完整掌握个人双选选择及配对结果；支持导出个人本年度招生学生明细，留存备案个人双选数据。
4.4 院内学生功能模块
4.4.1 导师信息浏览
学生可登录系统浏览本院所有可选导师的公示信息，包括个人简介、研究方向、科研成果、招生说明等基础内容，学生端全程不展示导师招生总名额、剩余可招人数。系统过滤规则：当年招生名额配置为0的导师，不在学生端导师列表展示，学生无法查看该导师信息，也无法向其提交志愿申请。
4.4.2 志愿填报与提交
按照学院辅导员设定的志愿数量填报多个意向导师，自主调整志愿顺序、替换志愿，提交意向后进入导师审核流程；在导师未审核、意向未锁定前可适度修改。若导师拒绝意向，学生将自动恢复意向填报权限，可重新选择其他导师；若导师确认意向或双选截止后，志愿自动锁定，学生无法修改、撤销志愿。师生双向选定配对生效后，学生无权自主解除、撤销、更改导师选择结果，无法私自改选其他导师。
4.4.3 个人进度与结果查询
学生可实时查看个人志愿审核进度、意向状态，双选全部结束后可查询个人最终配对导师信息，支持结果自主查看，无全院公示页面。
4.5 系统通用模块
4.5.1 消息通知模块
系统支持关键节点消息通知，双选通道开启、截止提醒、导师意向审核结果、二轮补选开启等重要节点，可通过系统站内消息提醒对应师生，保障双选工作有序推进。
4.5.2 日志记录模块
全程记录所有角色的操作日志，包含账号登录、信息修改、志愿填报、意向审核、名额调整、配对解除、数据导出等所有操作，日志永久留存、可追溯、不可篡改，保障双选工作公平合规、有据可查。
4.5.3 数据导出模块
支持多类型、多维度数据报表导出，包含师生配对总表、分专业明细表、导师招生汇总表、未匹配学生统计表、导师名单表格（含招收学生数量填报列）等，所有导出文件为标准Excel格式，适配学院归档、上报、打印使用需求。双选全部结束后，研究生辅导员可一键导出本院全部双选结果表；科研秘书可导出导师名单表格，填写招收学生数量后批量导入系统，实现导师招生名额批量设置。
5 系统核心约束与规则汇总
1. 权限约束：四级角色权限严格隔离，仅研究生辅导员拥有配对结果解除、二轮补选开启、名额微调权限；科研秘书仅负责年度名额录入；导师仅查看意向自己的学生；学生无任何数据修改、结果调整权限。
2. 展示约束：学生端全程隐藏导师招生总名额、剩余名额，名额校验仅在后台执行，满员后提交志愿自动提示失败；当年招生名额为0的导师，不在学生导师列表展示。
3. 流程约束：首轮双选结束后二轮通道不自动开启，必须由辅导员手动开启并配置时间；二轮仅对未匹配学生开放，已匹配学生禁止参与。
4. 数据约束：导师基础信息长效存储，无需年度全量导入，仅常态化增删改查；学生信息每届独立导入归档。
5. 锁定约束：师生双向确认配对后自动锁定，任何角色不得私自修改、解除，仅辅导员可特殊调整。
6. 志愿约束：导师拒绝学生意向后，学生自动恢复填报权限，不占用志愿次数；各轮次截止后志愿自动锁定，禁止修改。
