# 研途 · 研究生导师双向选择系统

面向单学院的可运行 B/S 应用。FastAPI 提供后端接口，SQLite 持久化数据，原生 JavaScript 提供中文响应式页面。不依赖前端构建、外部 CDN、邮件或第三方密钥。

## 快速运行

需要 Python 3.12+。在项目目录执行：

```bash
bash scripts/setup.sh
.venv/bin/python -m app.seed --demo
bash scripts/start.sh
```

服务默认监听本机 `127.0.0.1:8000`。浏览器打开该地址；API 文档位于 `/docs`。需要其他监听地址时，通过 `BIND_HOST` 设置。`--demo` 只会在空数据库中创建示例数据，有账号时不会重置或覆盖。

当前云环境已安装依赖并初始化演示数据。默认数据库为 `data/system.sqlite3`，可以通过 `DATABASE_PATH` 切换为另一个数据库文件。数据、虚拟环境与运行产物均被 Git 忽略。

## 已实现功能

- 五类角色的真实登录与后端授权，管理岗权限可收回，账号停用与密码重置立即使会话失效。
- 学年创建、切换、独立学生名录；导师信息跨年保留，新学年招生名额重新配置。
- 首轮志愿数量、时间和专业总额配置；到期自动关闭。二轮只能由辅导员开启，首轮未匹配名单固定。
- 学生多志愿填报、修改顺序、替换导师、撤回和进度查询；拒绝后释放有效志愿额度。
- 导师确认/拒绝、按成绩与时间排序、个人资料提交与辅导员审核、历年记录。
- 事务内校验和扣减名额，避免并发超招或重复配对；只有辅导员可解除或调剂配对。
- 辅导员调剂建议：同专业、成绩降序、已有志愿优先、剩余名额优先；预览后确认才执行，整批事务提交。
- 标准 `.xlsx` 师生新增导入、名额更新导入、错误行报告、模板下载、配对总表与分专业明细导出。
- 站内节点通知与工作提醒、专业进度、最终审核、归档快照、操作日志和哈希链验证。

## 从空数据库开展真实工作

不要将演示账号作为真实部署账号。指定新的数据库，创建管理员：

```bash
export DATABASE_PATH=/absolute/path/to/production.sqlite3
bash scripts/setup.sh
.venv/bin/python -m app.seed --admin
bash scripts/start.sh
```

`--admin` 默认通过交互方式读取账号和密码，也支持 `ADMIN_USER`、`ADMIN_PASSWORD`、`ADMIN_NAME` 环境变量。密码不写入脚本或日志。登录后：

1. 超级管理员创建学年，新增并授权辅导员、科研秘书账号。
2. 辅导员新增/导入导师与本届学生。学生导入包含初始密码列，至少10位。
3. 科研秘书下载导师名额表格，填写后导入，或逐个设置。
4. 辅导员设置志愿数量、首轮时间窗口和可选专业上限，开启首轮。
5. 学生填报，导师审核。到期后首轮关闭，结果锁定。
6. 辅导员微调名额，手动开启二轮；仅首轮未匹配学生可参与。
7. 二轮结束后处理异常与人工调剂，审核最终结果、导出全套报表并归档。
8. 超级管理员创建下一学年，导师名录保留，学生与名额按新学年重新配置。

所有界面时间按北京时间（Asia/Shanghai）显示，数据库统一使用带时区的 UTC 时间。关闭轮次后不能重新打开该轮，归档后配对结果、报表和统计快照只读。

## 运行与维护

`scripts/start.sh` 启动后端和静态页面；后端每10秒检查截止时间，业务接口也会同步检查，因此不会因定时线程延迟放过过期提交。Cookie 登录有效期8小时。生产环境应经 HTTPS 反向代理访问，并设置 `COOKIE_SECURE=1`；不应把开发监听端口直接当成公网服务。

SQLite 使用 WAL、外键和写事务，适合单学院轻量部署。多实例、高并发部署需另行迁移 PostgreSQL、集中会话/限流与任务调度。通知目前是站内消息。调剂建议采用可解释规则，不推断未采集的研究兴趣，也不替代辅导员确认。

日志有数据库禁止修改/删除的触发器和完整性哈希链，可检测常规篡改；拥有数据库文件管理权的人员仍可绕过应用。需满足严格“永久不可篡改”要求时，应配置外部只写审计存储及学院留存策略。

在线备份（可包含未检查点的 WAL 数据）：

```bash
.venv/bin/python scripts/backup.py
```

恢复时停止服务，使用备份数据库作为新的 `DATABASE_PATH` 后再启动。备份包含师生个人信息，应按学院权限保存。演示数据不包含真实个人信息。

技术设计、权限矩阵与规则冲突处理见 [docs/design.md](docs/design.md)，原始需求见 [docs/requirements-original.txt](docs/requirements-original.txt)。
